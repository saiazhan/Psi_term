# PsiTerm

Веб-панель управления устройствами и серверами через SSH. Сейчас это **интерактивный frontend-прототип**, а не готовая система авторизации или удалённого доступа.

## Что уже есть

- Демонстрационный экран входа.
- Обзор и список устройств с CPID, NAME и IP.
- Страница устройства с вкладками «Файловый менеджер», «Терминал» и «Информация».
- Виртуальная навигация по тестовой структуре каталогов.
- Демо-админка для добавления, редактирования и удаления пользователей и устройств.
- Уровни доступа Simple, Expert и Admin.
- Черновик PostgreSQL-схемы в `database/schema.sql`.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-сервера можно выполнить:

```bash
python -m SimpleHTTPServer 8000
```

Затем откройте `http://localhost:8000`.

Любой непустой логин и пароль откроют демонстрационный интерфейс. Логин `admin` показывает административные разделы. Это **не настоящая проверка пароля**.

## Важно: ограничения прототипа

- Данные устройств и пользователей хранятся только в памяти страницы и сбрасываются после перезагрузки.
- Пароли не сохраняются и не отправляются на сервер.
- PostgreSQL пока не подключён.
- SSH-подключения, терминал, загрузка и скачивание файлов пока не реализованы.
- Не вводите реальные учётные данные и не публикуйте прототип как защищённую панель.

## План backend

Рекомендуемый следующий этап — отдельный backend на поддерживаемой версии Python с PostgreSQL:

1. Сессии, безопасная авторизация, хеширование паролей и контроль ролей на сервере.
2. CRUD для пользователей и устройств с проверкой разрешений.
3. SSH через библиотеку с поддержкой SFTP; не передавать произвольные команды из браузера без серверной политики.
4. Файловые операции с проверкой разрешённых каталогов, ограничением доступа и журналированием.
5. HTTPS, CSRF-защита, ограничение попыток входа, секреты вне репозитория и аудит действий.

Python 2.7 и Ubuntu 12.04 сняты с поддержки и небезопасны для публичного сервиса. Для реального развёртывания используйте поддерживаемую ОС и Python 3. Старую платформу можно рассматривать только как отдельное ограничение совместимости, но не как безопасную production-среду.

## Структура

- `index.html` — интерфейс.
- `styles.css` — оформление.
- `app.js` — демонстрационная логика.
- `database/schema.sql` — начальная схема PostgreSQL.
